# Final React Frontend

## Start

```bash
npm install
npm run dev
```

The frontend expects the FastAPI service at `http://127.0.0.1:8000` by default.

You can override it with:

```text
VITE_API_BASE_URL=http://127.0.0.1:8000
```

The dashboard uses the same Python `optimizer.py` models as the original Streamlit application.
